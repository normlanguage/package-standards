# Norm 包与仓库规范

[English](README.md)

[规范正文](docs/standard.zh-CN.md)是要求的唯一维护位置，各仓库链接引用，不复制后分别维护。

规范覆盖模块边界、命名、公共 API、仓库结构、文档、可运行示例、许可证、可复现构建、不可变发布和消费者验收。应用、编译器和基础设施遵守适用的交付要求，不机械套用库命名规则。

语言语义以 [Norm 模块系统](https://github.com/normlanguage/Norm/blob/main/docs/spec/module-system.md)为准。共享包自动化维护在 [registry](https://github.com/normlanguage/registry)。

通过 Pull Request 修改规范。每项要求应有明确的维护归属和可执行的验证方法；模板、自动化不能成为第二套规则来源。
